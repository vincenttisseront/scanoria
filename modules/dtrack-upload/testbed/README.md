# Banc d'essai de dtrack-upload

SBOM CycloneDX 1.6 minimal (`sbom.cdx.json`, un composant : minimist 1.2.8,
licence MIT), envoyé au Dependency-Track installé sur le projet
`scanoria-testbed`, version `testbed`. L'attente vérifie que le composant est
relu dans l'inventaire du projet après traitement : envoi, traitement et
relecture fonctionnent avec la clé d'API créée par l'appliance.
