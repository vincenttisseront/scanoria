# Banc d'essai de Semgrep CE (piégé volontairement)

Même code inerte que celui d'Opengrep. Sans jeu de règles rattaché, le banc
d'essai lance les règles maison de Scanoria (même syntaxe) : les règles
officielles Semgrep ne sont jamais embarquées.
